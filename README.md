\# Цифровий археолог



Каталог знахідок з розкопок із координатами, фотографіями, датуванням та історією змін.



\## Функції



\- каталог знахідок із пошуком і фільтром за датуванням

\- картка знахідки з координатами, фото та походженням

\- журнал автора й часу кожної зміни запису

\- обмеження доступу до чутливих даних про місця знахідок
